# React Profile

Optional profile for React applications that use CSS Modules and optionally React Query.

## Adds skills

- `frontend-patterns`

## Adds agents

- `frontend-reviewer`
- `ux-reviewer` when a running browser app exists

## Activation criteria

Use when the repo has React files or tasks touch:

```text
**/*.tsx
**/*.hook.ts
**/*.module.css
**/store/*.ts
**/context/*.ts
```

## Warning

This profile is intentionally opinionated: no Tailwind, no utility CSS frameworks, no prop destructuring, no context for shared state, and no reducers by default.
