# Browser QA Profile

Optional profile for applications that can be exercised through a browser.

## Adds agents

- `functional-qa`
- `ux-reviewer`

## Recommended MCP

- Context7 for framework and library documentation.
- Playwright MCP for browser automation, accessibility snapshots, console checks, and network checks.

## Preconditions

- The app must be running locally or in an accessible environment.
- README must document startup commands, URLs, and test credentials.
- The user must provide a spec, PRD, route, or flow to test.
