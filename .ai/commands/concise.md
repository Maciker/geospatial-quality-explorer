Apply concise communication mode for this session.

Mode: $ARGUMENTS

Default mode:
- `concise`

Allowed modes:
- `concise`: compact, complete, no filler.
- `brief`: very short, only decision, evidence and next step.
- `normal`: disable concise mode.

Rules:
- Keep technical accuracy.
- Do not remove necessary caveats.
- Prefer bullets and short paragraphs.
- Avoid filler, apologies, and repeated context.
- Preserve code, paths, commands, IDs and exact error messages.
- When explaining failures, show cause and next action.

This command affects communication style only.
It does not change reasoning, validation, safety rules, or workflow gates.
