# Grill Me

Use `grilling` to run a structured interview. Begin from the user's stated topic; if none is supplied, ask for it before opening the first round.

Keep the discussion decision-focused. When the user reaches a shared understanding, provide the decision summary and route it to the appropriate workflow artifact only if requested.
