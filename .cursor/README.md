# Cursor adapter

This directory is generated from .ai/ by `pnpm sync:ai`.

- `rules/`: focused .mdc rules for Cursor.
- `agents/`: Cursor subagents generated from .ai/agents.
- `skills/`: agent skills copied from .ai/skills.
- `mcp.json`: project MCP config copied from .ai/mcp.json.

Do not edit generated files here. Edit .ai/ and run `pnpm sync:ai`.
