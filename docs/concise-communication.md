# Concise Communication

Concise communication reduces context noise while keeping accuracy.

## Command

```text
/concise
/concise brief
/concise normal
```

## Rules

- Keep substance.
- Remove filler.
- Preserve exact paths, commands and errors.
- Keep uncertainty when important.
- Do not hide tradeoffs.
- Do not omit validation evidence.

## Recommended default

Use concise mode for operational workflow messages.

Use normal mode for tutorials, architecture explanations and documentation.
