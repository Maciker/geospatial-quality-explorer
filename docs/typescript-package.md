# TypeScript Package

`agent-workflow-code-ts` contains concrete TypeScript guardrails and quality tooling.

## Includes

- TypeScript configuration;
- ESLint;
- Vitest;
- dependency-cruiser;
- knip;
- jscpd;
- TypeScript quality runner;
- vendor projections for this package.

## Does not own

- universal workflow language;
- technology-agnostic code workflow language;
- proposal or other business-function workflows.
