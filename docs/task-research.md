# Task Research

Task research investigates a specific change area before planning.

## Difference from repo discovery

- `/repo-discovery` maps the repository.
- `/task-research` investigates one task.
- `/discovery` clarifies problem, success criteria and constraints.

## Output

```text
.ai/workspace/tasks/<task-id>/research.md
```

## Rules

- Read-only.
- Factual.
- No implementation.
- No broad refactor proposals.
- Separate facts from hypotheses.
