# Human In The Loop

The human role does not disappear. It moves to scope, decisions, review and risk acceptance.

## Human decisions

Humans approve:

- task scope;
- implementation plan;
- risky tradeoffs;
- baseline changes;
- final merge readiness.

## Agent responsibilities

Agents can reduce mechanical work by:

- mapping a repo;
- drafting discovery artifacts;
- proposing plans;
- implementing approved small slices;
- collecting validation evidence;
- producing structured review findings.

## Stop conditions

Stop and ask for human input when:

- requirements are ambiguous;
- the plan grows beyond one reviewable slice;
- validation requires changing scope;
- secrets, data deletion or production access are involved;
- the agent would need to grow a quality baseline.
