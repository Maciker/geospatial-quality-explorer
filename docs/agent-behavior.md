# Agent Behavior

Agents must produce small, deliberate, verifiable changes.

## Principles

1. Think before acting.
2. Simplicity first.
3. Surgical changes.
4. Goal-driven execution.

## Minimal diff checklist

- Every changed file maps to the approved plan.
- Every changed line has a reason.
- No unrelated formatting.
- No drive-by refactor.
- No speculative abstraction.
- No extra feature.
- Validation evidence exists.

## Review usage

Reviewers should flag:

- hidden assumptions;
- over-engineering;
- broad changes;
- unrelated cleanup;
- vague validation;
- missing evidence.
