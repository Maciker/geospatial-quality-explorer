# Split Architecture

This package is no longer the final monolithic product. It is the TypeScript specialization of a broader workflow family.

## Belongs in core

- discovery, plan, execute, review, validate, summarize;
- trust model;
- context budget;
- task workspace;
- progress compaction;
- agent behavior.

## Belongs in code core

- repo discovery;
- task research;
- minimal diff;
- code review layers;
- worktree policy;
- quality baseline policy.

## Belongs in TypeScript

- pnpm;
- tsconfig;
- ESLint;
- Vitest;
- dependency-cruiser;
- knip;
- jscpd;
- TypeScript quality runner and ratchet implementation.
